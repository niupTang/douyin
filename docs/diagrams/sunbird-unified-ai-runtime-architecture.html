Sunbird OS · 统一 AI 服务层

SQLite 统一配置与任务数据 · 跨平台密钥保护 · Python 内置 Agent Runtime

方案结论

A · Electron Runtime

继续使用 Node sidecar，Python 只提供数据 API。

问题：生命周期、配置、日志和测试仍然分裂。

已选方案

B · Python 内置 Runtime

结构化 Agent 与工具 Agent 共用配置、模型路由、密钥和任务系统。

前端不直连模型，Electron 不持有日常 AI 密钥。

C · 独立 Agent 服务

把 Runtime 拆成额外本地服务或云端服务。

问题：当前桌面单机产品的部署与运维成本过高。
