# 抖音采集与作品预览共用会话

用户已确认：由自动化浏览器管理会话，点击作品时在同一个 BrowserContext 中打开独立标签页。

所有共享 Playwright 操作由一个后台线程中的事件循环执行，避免 Flask 请求线程和 asyncio.run 的临时循环交叉使用浏览器对象。按 Cookie 文件的绝对路径区分账号；没有账号文件时使用默认抖音会话标识。明确选择的账号优先于旧 Electron 会话。

会话管理器保留 BrowserContext。采集、搜索和备用媒体下载分别创建任务页，并在任务结束或异常时关闭任务页。预览页独立保留，手动登录和验证产生的 Cookie、localStorage 可立即由同会话的自动化页面使用。手动关闭整个浏览器后，下次操作重建会话。退出后端时释放上下文与浏览器。

作品链接通过受认证的后端 POST 接口打开，只接受 HTTPS 的 douyin.com 及其子域。前端不再使用 target=_blank 打开相关作品；登录按钮也进入共享浏览器。保存会话按钮将当前上下文的 storage_state 写回对应账号文件，供后续启动和下载使用。

验证覆盖并发任务复用、账号隔离、预览保留、任务页清理、手动关闭后的重建及链接校验；另以本地拦截页面验证真实 Chromium 的 Cookie 与 localStorage 共享，不使用真实账号或发布操作。
