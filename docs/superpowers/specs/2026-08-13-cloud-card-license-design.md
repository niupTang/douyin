# 云端卡密与本地许可证设计

Sunbird OS 首版不要求用户注册账号。用户输入购买卡密后，Electron 将卡密、随机生成的稳定设备 ID 和应用版本提交给独立云端认证项目。每张卡密默认只允许一台活跃设备；换机由云端后台撤销旧设备。

云端使用 Ed25519 私钥签发版本化许可证。本地 Python 后端随安装包内置对应公钥，独立验证签名、设备 ID、商业到期时间、7 天离线截止时间和功能权益。Vue 只展示授权状态；Python 是采集、AI 分析、口播生成、发布和指标同步的最终权限执行点。

Electron 使用 `safeStorage` 保存设备 ID、设备刷新凭据和许可证，不保存原始卡密。云端数据库只保存刷新凭据 SHA-256 摘要。每次应用启动时 Electron 优先联网刷新许可证；网络不可达时把本地许可证注入 Python，由 Python 判断是否仍处在离线期限内。

云端认证项目不接收抖音 Cookie、视频、转录、拆解、口播稿或本地 AI 数据。授权失效后付费写入与执行能力被拒绝，但本地已有数据仍允许查看和导出。
