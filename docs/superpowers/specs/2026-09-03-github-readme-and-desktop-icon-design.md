# GitHub README 与 Windows 图标更新设计

## 目标

让仓库首页准确说明当前的 Sunbird OS 产品能力，并让 Windows 桌面端在安装包、桌面快捷方式、开始菜单、任务栏和主窗口中使用统一的太阳鸟图标。

## 范围

### README

根目录 `README.md` 作为 GitHub 首页，重写为面向使用者和贡献者的单一入口：

- 产品定位：本地化的内容运营、对标研究和口播工作台。
- 现有能力：账号管理、抖音会话同步、对标采集与分析、选题雷达、口播工作台、素材管理和多平台发布。
- 安装、开发、测试和 Windows 打包命令。
- 仓库结构和 iOS OpenPrompter 的定位。
- 贡献与安全说明，明确排除发布包、浏览器缓存、模型、账号 Cookie、日志、个人设置和媒体输出。

README 不把未实现或已经移除的功能描述为可用功能，也不包含认证私钥、令牌、用户数据或授权机制细节。

### Windows 图标

使用项目内现有太阳鸟图形源图，生成包含 16、20、24、32、40、48、64、96、128、256、512 像素尺寸的 Windows `.ico` 文件。图标采用用户选择的 A 方案：象牙白底与安全留白，以保证小尺寸清晰度。

`electron-builder` 的 Windows 配置引用此图标，使 NSIS 安装包、便携版、安装后的程序和开始菜单使用统一资源；Electron 主窗口在开发和打包运行时也显式引用同一图标。

## 实施边界

- 修改：`README.md`、图标资源、Electron 打包/窗口配置，以及必要的 `.gitignore` 规则。
- 验证：检查 `.ico` 是否含多种尺寸，构建 Windows 包，并检查产物可执行文件图标资源。
- 提交：仅包含源码、测试、配置、文档和图标资源。
- 不提交：`release/`、`release-final/`、`build/`、`dist/`、`.npm-cache/`、`.playwright-cli/`、`.superpowers/`、模型、日志、视频、数据库、Cookie、个人设置与密钥。

## 风险与处理

- 原始上传图标的临时文件已失效，因此使用仓库内与其同一太阳鸟视觉体系的 iOS 图标源文件。
- Windows 快捷方式只会在安装新版后更新；已存在的旧快捷方式需要重新安装或手动刷新。
- 图标仅影响桌面产品外观，不改变授权、账号、数据库或业务行为。
