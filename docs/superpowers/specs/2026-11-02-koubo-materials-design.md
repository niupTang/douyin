# 口播项目素材与抽帧

用户已确认在口播工作台中实现第一版素材编辑布局，底层处理使用 FFmpeg。

页面默认展示素材标签页：左侧选择和上传项目素材，中间预览与定位，右侧显示媒体属性及保存当前画面。原有文案提词、模板任务、封面和发布操作保留在独立标签页。

上传视频由 ffprobe 验证并读取时长、分辨率、平均帧率。素材沿用口播项目的存储和应用登录鉴权；原始文件名仅作为显示信息，实际存储使用 UUID。抽帧由 FFmpeg 解码指定时间点并保存原始分辨率 PNG，素材记录保留来源视频 ID、名称、时间点。已有素材表自动新增 metadata JSON 列，既有记录默认空对象。

前端用浏览器播放器预览，上一帧/下一帧按平均帧率步进，可变帧率时不承诺逐帧精确。浏览器不支持的编码显示提示。复杂时间线、动画、AI 自动选材和语义搜索不在本版范围内。

新增后端逻辑放入 backend_app/modules/video_materials，口播蓝图仅负责装配；文件保存在现有 koubo_data/projects 内。校验应用登录状态、源文件存在、时间点有限且位于视频范围。无 FFmpeg、格式错误和处理超时均返回可读错误。

验证包括实际生成视频、上传、探测、抽帧 PNG 尺寸和来源元数据；错误输入、鉴权和已有口播测试，以及 Vue 生产构建。

口播页面无需单独输入令牌；控制接口复用应用签名登录凭证，媒体内容 GET 支持同一登录凭证通过查询参数传递。手机与工作器仍使用设备绑定令牌。
