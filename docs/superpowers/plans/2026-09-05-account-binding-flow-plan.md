# 账号绑定流程修复实施计划

1. 为账号表迁移和命名对象查询补回归测试，扩展 `user_info` 字段、唯一索引和仓储接口。
2. 为账号幂等绑定与重新登录身份冲突补测试，将数据库写入从平台浏览器代码迁到账号服务。
3. 为公开 `/login`、随机登录会话和结构化 SSE 补测试，修复后端路由与会话清理。
4. 更新账号管理前端：移除 SSE URL token、生成会话 ID、消费结构化事件和命名对象响应。
5. 将 `/getValidAccounts` 改成纯查询，增加单账号验证接口及相应测试。
6. 运行聚焦 pytest、前端构建和变更检查，记录尚需真实抖音环境验证的部分。
